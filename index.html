INSTALLATION

Up and running in a minute

01

Mac

  1. Download Mayhem-Pocket-v1.4.dmg.
  2. Open your Downloads folder and double-click the DMG.
  3. Drag Mayhem Pocket into the Applications folder.
  4. Open Applications, then double-click Mayhem Pocket.
  5. If macOS blocks it, Control-click the app, choose Open, then click Open again. You only need to do this once.
  6. After it opens, you can drag its icon from Applications to your Dock for quick access.
02

Windows

  1. Download Mayhem-Pocket-Windows-x64-Portable.zip.
  2. Open your Downloads folder. Right-click the ZIP, choose Extract All, then click Extract.
  3. Open the newly extracted Mayhem-Pocket-Windows-x64 folder.
  4. Double-click Mayhem Pocket.exe to start the app. Keep every file in this folder together.
  5. If SmartScreen appears, click More info, confirm the app name, then choose Run anyway if you trust this download.
  6. For a desktop shortcut, right-click Mayhem Pocket.exe, choose Show more options if shown, then select Send to → Desktop (create shortcut).
  7. From then on, double-click the Mayhem Pocket shortcut on your desktop. The custom icon is included automatically.
Windows note: Do not move only the EXE out of its folder—the supporting files beside it are required. Create a shortcut instead.
